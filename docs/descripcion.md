# Descripción del proyecto

**Organizador Personal** es la estructura inicial de una aplicación pensada para
administrar tareas y notas personales de forma sencilla.

El propósito de esta etapa no es programar la aplicación, sino preparar
correctamente el entorno de trabajo: estructura del proyecto en Visual Studio
Code, entorno virtual de Python, gestión de dependencias y control de versiones
con Git y GitHub.

Más adelante, el proyecto podría crecer para permitir registrar tareas,
consultarlas, modificarlas, marcarlas como terminadas y guardar notas asociadas.
